**Access date:** 2026-10-02 (Asia/Shanghai)

## Finding

The public dataset is `modelscope1553926531/BRPHM-datasets` at [ModelScope](https://www.modelscope.cn/datasets/modelscope1553926531/BRPHM-datasets). The registered study data are the `SIM_bat` and `SIM_rwa` simulation partitions, not the unrelated third-party datasets also archived by this collection. ModelScope's current dataset-detail API declares the collection license as `CC-BY-4.0`; neither inspected Git commit contains a versioned license file, and the README itself only records a publisher declaration of public-release authorization. The platform license value is therefore directly evidenced as current ModelScope metadata, but is not independently pinned inside either commit.

No DOI is exposed by the dataset-detail API or README. Exact-name searches returned zero DataCite records and zero exact-title Crossref matches as of the access date. Report DOI as “not assigned/disclosed by the inspected sources”; do not invent one or leave the field implicit.

## Upstream-Source Boundary

The collection README and `PROVENANCE.json` also list external battery, bearing, and turbofan source families. Those are separate archived partitions; they are not the 648-unit `SIM_bat`/`SIM_rwa` split in the F2 manifest. The provenance field named `license_cite` contains bibliographic citation strings, not license identifiers. As a primary-source cross-check, the unrelated NASA Open Data [“Randomized and Recommissioned Battery Dataset” page](https://data.nasa.gov/dataset/randomized-and-recommissioned-battery-dataset) marks the rights metadata as `other-license-specified` and gives `https://www.usa.gov/government-works` as its license URI (page title as retrieved: “Randomized and Recommissioned Battery Dataset - Dataset - NASA Open Data Portal”; HTTP 200; fetched body SHA-256 `730fd6ed556ca1bc23927c8c17fbd283a69fec0ffe9a0c56c6c1f6fa3ece5773`). That condition must not be represented as the license of the internally generated simulation partitions. Other archived source families retain their own source-specific notices and are outside this study's analyzed data subset.

The F2 manuscript should identify the exact ModelScope commit and its root/tier manifest hash, state that the analyzed inputs are internally generated `SIM_bat` and `SIM_rwa`, report the observed ModelScope metadata license as `CC-BY-4.0` with access date, and explicitly say that the checked commits lack a standalone license file. The repository-level license field does not establish that every unrelated upstream item in the full collection has identical terms.
